# Dify_salong

基于 Dify 搭建航空制造场景智能知识库问答工作流的技术沙龙实施与复现记录仓库。

GitHub 仓库：[xupengfeng/Dify_salong](https://github.com/xupengfeng/Dify_salong)（公开仓库，默认分支 `main`）。

项目面向课题组研发人员，通过知识库数据治理、检索对照和工作流编排，训练研发工程能力、业务分析师（BA）的数据与流程建模能力，以及产品经理（PM）的需求边界和交付闭环意识。完整目标与阶段提示词见[原始实施方案](dify.md)。

## 当前状态

本机 Dify 1.18.0 基础服务已运行，管理员已初始化并登录，本机入口为 `http://localhost:8080`。模型凭据配置、真实 LLM/Embedding 调用及最小知识库与 Chatflow 验收尚未完成；实际证据见[本机部署执行记录](docs/runs/2026-10-31-local-deployment.md)。先在本机完成实验，实验顺利结束后再在远程服务器搭建课题组共享环境。

2026-10-31 已确定模型来源：课题组模型平台（OpenAI 兼容公网接口），计划采用 LLM `deepseek-flash` / `deepseek-v4-pro`、Embedding `BAAI/bge-m3`；平台无 Rerank 模型，知识库调优组改用混合检索权重模式。阶段零的配置样例与步骤见 [deploy/](deploy/README.md)，基础部署已实际执行，模型接入仍待完成。

原方案中的“已经部署”“已完成实验”等文字属于后续阶段提示词的背景模板，具体完成范围以运行记录为准。当前尚未完成实验语料构建、A/B 检索对照或完整问答工作流验证。

航空工艺语料计划采用教学合成数据。其材料参数、标准代号与检验条款不能直接作为真实生产的受控工艺依据。

## 六阶段路线与成果

| 阶段 | 主要工作 | 后续应保存的成果 |
| --- | --- | --- |
| 0：环境与模型 | 先在本机部署固定版本并接入 LLM、Embedding（平台无 Rerank），完成最小验证；远程共享环境待本机实验顺利结束后搭建 | 本机部署方案、版本与资源记录、脱敏配置、模型接入记录；后续远程复现与迁移说明 |
| 1：语料治理 | 构建原始合成语料，清洗表格并设计分段 | 原始与清洗语料、转换脚本、数据说明与文件哈希 |
| 2：检索对照 | 比较知识库 A 与 B 的召回效果 | 全部参数、黄金题及依据、实际召回结果、截图与失败案例 |
| 3：问答编排 | 实现意图分类、术语改写、检索、判空、生成与兜底 | 工作流 DSL、节点提示词、变量绑定与导入说明 |
| 4：调试与边界 | 运行正向多跳问题和越界需求案例 | 节点追踪、真实输出、分值、延迟、Token、需求判别矩阵 |
| 5：材料与预演 | 用实测成果制作课程材料，完成成员视角预演 | 四套材料、DSL 备份、预演记录与实际用时 |

最终四套交付材料为《原理介绍》《技术逻辑与实现过程》《实验课程资料》《巩固练习材料》。
